# Искусственный интеллект мобов (Bowl 2D)

## Обзор

Модули в этой папке описывают поведение враждебных и нейтральных сущностей на карте.
Решения принимаются каждый кадр в `mob_brain.py` и передаются в физический движок как желаемое ускорение.

## Типы врагов

| Тип | Цвет | Поведение |
|-----|------|-----------|
| **grazer** (травоядный) | Зелёный | Ищет зелёные точки, убегает от более крупных. Не охотится на игрока. |
| **hunter** (охотник) | Красный | Агрессивно преследует игрока и меньших врагов в большом радиусе. Зелёные точки игнорирует. |
| **lurker** (засадник) | Янтарный | Медленно патрулирует. При приближении игрока — короткий рывок преследования. |

## Общие правила

1. **Побег** — если рядом есть сущность **крупнее** (радиус больше на `flee_size_margin`), моб убегает от ближайшей угрозы.
2. **Патруль** — бродит между waypoints внутри чаши, если нет других целей.

## Босс

После водоворота появляется один случайный босс из пяти типов (`boss_kinds`).

| Тип | Особенность |
|-----|-------------|
| **titan** | Огромный, медленный, много HP, сильный урон |
| **stalker** | Кружит вокруг игрока, затем рывок |
| **swarm** | Держит дистанцию, периодически призывает охотников |
| **leech** | Быстрый, крадёт красную шкалу и растёт при ударе |
| **vortex** | Орбита + рывки, притягивает игрока |

Файлы:

- `mob_brain.py` — поведение обычных мобов.
- `boss_brain.py` — поведение боссов.
- `bosses.py` — создание боссов и эффекты ударов.

| Ключ | Описание |
|------|----------|
| `enemy_kinds` | Список типов врагов |
| `enemy_kind_weights` | Веса при случайном спавне |
| `ai_flee_radius` | Радиус обнаружения более крупных существ |
| `hunter_aggro_radius` | Радиус агрессии охотника |
| `lurker_ambush_radius` | Дистанция срабатывания засады |
| `lurker_burst_duration` | Длительность рывка засадника |

## Файлы

- `mob_brain.py` — расчёт желаемого направления движения (`MobIntent`).
