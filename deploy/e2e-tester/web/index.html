E2E Tester

Loading…

Универсальный on-demand сервис браузерных E2E. Один Docker-контейнер, SQLite в volume (сайты, сценарии, креды, отчёты). Без отдельного Postgres.

Sites

Реестр целевых сайтов (base_url). При старте сидируется copyparse → https://www.copyparse.ru

Credentials

Логин/пароль для сайтов. Можно задать здесь или прямо в Builder. Секреты шифруются Fernet.

Discovery — обход сайта

Бот рекурсивно обходит сайт (same-origin), собирает ссылки и интерактивные элементы (кнопки, submit). Отметьте нужные и создайте сценарий или отправьте в Builder.

Требования

        
    
          
  1. Docker на локальном ПК.
    2. 
          
  2. Исходящий HTTPS для публичных сайтов; для сайта на хосте — host.docker.internal.
    3. 
          
  3. Данные в SQLite volume tester_data — отдельный Postgres не нужен.
    4. 
        

      


      

        
Запуск тестера

        
Панель: http://127.0.0.1:8300

        
cp deploy/e2e-tester/.env.example deploy/e2e-tester/.env
# Fernet: python -c "from cryptography.fernet import Fernet; print(Fernet.generate_key().decode())"

docker compose -f deploy/e2e-tester/docker-compose.yml --env-file deploy/e2e-tester/.env up -d --build

      


      

        
Discovery

        
    
          
  1. Выберите site / URL, опционально login + credentials.
    2. 
          
  2. Start — бот обходит same-origin ссылки до max_pages / max_depth.
    3. 
          
  3. Собирает links, nav, buttons, inputs.
    4. 
          
  4. Отметьте элементы → В Builder или Создать сценарий.
    5. 
        

      


      

        
Builder и загрузка

        
    
          
  1. Builder — форма: base URL, логин/пароль (или готовый credential), список разделов (path + assert text) и кнопок (text/selector).
    2. 
          
  2. Scenarios → Upload — загрузить свой JSON/YAML/.py файл в БД.
    3. 
          
  3. Preview JSON — посмотреть сгенерированный сценарий до сохранения.
    4. 
        

      


      

        
JSON schema v2

        
Иерархия: sections → subsections → actions / on_enter. После ошибки раздела прогон продолжается; итоговый run = failed, если упал хотя бы один узел.

        
Пример: examples/copyparse_smoke_v2.json для https://www.copyparse.ru.

    2.

    3.
