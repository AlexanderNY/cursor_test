# Серия networks

Короткие выпуски под дыры собеседования. В каждом есть ответ вслух и плохой ответ.

| Ep | slug | Тема |
|----|------|------|
| NET01 | `net-dns-http` | DNS и HTTP на собеседовании |
| NET02 | `net-tcp-udp` | TCP и UDP |
| NET03 | `net-tls` | TLS: что обещает HTTPS |
| NET04 | `net-interview-drill` | Сети: короткий ответ на собеседовании |
