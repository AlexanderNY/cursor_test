# Серия Product Learn: Junior → Senior

Карта **12 выпусков** для трека product owner / PM. Полные тексты: `pm*.md` (например `pm01-product-management.md`). Рубрика `product`.

Источники тем (публичные первоисточники; тексты статей — **оригинальные** разборы, не копипаст книг): [Intercom RICE](https://www.intercom.com/blog/rice-simple-prioritization-for-product-managers/), [SAFe WSJF](https://framework.scaledagile.com/wsjf/), [Scrum Guide](https://scrumguides.org/), [SVPG Articles](https://www.svpg.com/articles/), [Product Talk](https://www.producttalk.org/), [Google re:Work OKRs](https://rework.withgoogle.com/intl/en/guides/set-goals-with-okrs).
