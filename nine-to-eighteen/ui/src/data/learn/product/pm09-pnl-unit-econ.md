## Введение

PM понимает, как фича бьёт по деньгам.

## Раздел: Основы

Выручка, себестоимость, валовая маржа. Contribution margin — после переменных затрат.

## Раздел: Практика

Unit-экономика: LTV, CAC, payback (упрощённо). Не нужно быть CFO — нужно читать знак эффекта.

## Раздел: На собесе

Связь с OKR: денежные KR осторожно, но прозрачно.

## Лаба

**Цель.** Оценить влияние −10% churn на выручку (учебно).

**Шаги.**
1. Определите маржу.
2. Переменные vs постоянные.
3. LTV/CAC идея.
4. Риск vanity metric.
5. Вопрос к финансисту.

**В группу:** разберите «рост MAU без выручки».

**Готово, если…**
- [ ] Маржа понятна
- [ ] Unit-идея
- [ ] Не vanity

## Схема: Деньги

```mermaid
flowchart LR
  Revenue --> COGS --> GrossMargin
  GrossMargin --> Contribution
```

## Тест

### Contribution margin?

**Ответ:** после переменных затрат

**Пояснение:** Ближе к решению о масштабе.

### CAC?

**Ответ:** стоимость привлечения клиента

**Пояснение:** Сравнивают с LTV.

### Vanity metric?

**Ответ:** красиво, но не связано с ценностью/деньгами

**Пояснение:** MAU ради MAU.
