# Задание: обогатить статьи Learn (9to18)

Статьи — Markdown-файлы в `k:\Project\cursor_test\nine-to-eighteen\ui\src\data\learn\<папка>\*.md`.
Это учебные выпуски для подготовки к собеседованию (русский язык). Их читает парсер
`nine-to-eighteen/api/services/learn_article_md.py`. Формат статьи (не ломать):

- frontmatter между `---` — НЕ ТРОГАТЬ (slug, prerequisites, profiles и т.д.);
- `## Введение`, затем разделы `## Раздел: <Название>` (текст, можно с кодом в ```lang);
- `## Лаба`, `## Схема: <подпись>` + блок ```mermaid (схем может быть несколько),
  `## Тест`, `## Шпаргалка`, `## Anki`, `## Мнемоника`, `## Итоги`, `## Ссылки`.
- В старых выпусках разделы называются `## <Тема>: <Подраздел>` — это тоже нормально, формат тот же.
- Вопрос теста:

```
### Текст вопроса?

**Ответ:** короткий ответ

**Пояснение:** одно-три предложения, почему так.
```

Не трогать: frontmatter, `## Anki`, `## Мнемоника`, `## Ссылки`, `## Лаба` (кроме явных опечаток).
Не трогать никакие другие файлы (seed JSON, episodes.ts, база, код) — их обновит главный агент.
Не запускать docker, не коммитить.

## Шаг 1. Короткие эталонные ответы (во ВСЕХ статьях твоего списка)

Тест на сайте засчитывает ответ, если строка ученика СОДЕРЖИТ эталон `**Ответ:**`
(без учёта регистра). Длинный эталон набрать невозможно — ученик получает 0 за верное понимание.

- Каждый `**Ответ:**` — 1–4 слова, максимум 5: термин, команда, имя флага, короткая формула.
  Примеры: `SameSite`, `TRUNCATE`, `ссылочную целостность`, `нет, только отчёт`, `идемпотентность`.
- Форма слова — та, которую человек естественно напишет в ответе на вопрос.
  Если вопрос «Что проверяет FOREIGN KEY?» — ответ `ссылочную целостность`.
- Без скобок, «или», перечислений через запятую из трёх+ пунктов. Если ответ — список,
  перепиши вопрос так, чтобы ответ был одним ключом (или спроси про один элемент списка).
- Всё, что вырезал из ответа, перенеси в начало `**Пояснение:**` — смысл не теряется.

## Шаг 2. Три вопроса-ситуации (во ВСЕХ статьях твоего списка)

Добавь в конец `## Тест` три новых вопроса. Не определения, а решение в ситуации, как на собесе:
«Сессия в куке, чужой сайт шлёт POST на ваш API. Что поставите первым?» → `**Ответ:** SameSite`.
- Ситуация конкретная (данные, ограничение, симптом), 1–3 предложения.
- Ответ по правилам шага 1. Пояснение объясняет, почему не другие варианты.
- Не дублируй существующие вопросы и Anki.

## Шаг 3. Пример и вторая схема (ТОЛЬКО в статьях с пометкой [тонкая])

У тонких статей шесть разделов чистого текста, одна схема и ни одной строки кода.

a) Добавь раздел `## Раздел: Пример в коде` сразу после раздела `## Раздел: Разбор на примере`
   (если его нет — после последнего раздела `## Раздел:` перед `## Раздел: Ответ вслух`).
   Для нетехнических тем (продукт, Jira, метрики) назови `## Раздел: Пример на практике`.
   Содержание:
   - конкретный артефакт: код, конфиг, HTTP-запрос/заголовки, SQL, тест, YAML, таблица, заполненный шаблон;
   - пара «плохо → хорошо» там, где тема про ошибку (два блока кода с подписью перед каждым);
   - 120–250 слов пояснений между блоками: что важно в каждой строке и где ломается;
   - код рабочий и современный (Python 3.12, FastAPI, SQLAlchemy 2.0, React 18 + TS, Playwright,
     pytest, Celery 5, PostgreSQL 16, Kubernetes 1.30). Не выдумывай API — если не уверен, проще пример.
   - Пример продолжает сценарий статьи (те же сущности: заявки, заметки, заказ…), а не новый.

b) Добавь вторую схему: блок `## Схема: <подпись>` + ```mermaid сразу после существующей схемы.
   Схема показывает процесс из примера (часто `sequenceDiagram`, или `flowchart`, `stateDiagram-v2`).
   Правила mermaid 11: id участников латиницей без пробелов (`participant B as браузер`),
   НЕ называть участников/узлы словами-ключами (`loop`, `end`, `alt`, `opt`, `par`, `note`, `box`);
   подписи с символами `()<>{}:;,"` бери в двойные кавычки: `A["POST /orders (с кукой)"]`;
   в сообщениях sequenceDiagram избегай `;` и `#`. 6–12 шагов, не больше.

## Стиль текста

Русский, короткие предложения, как в соседних разделах статьи. Термины: «русское — English» один раз.
Без воды («в этом разделе мы рассмотрим»), без эмодзи. Англицизмы-кальки заменяй («легавый» → «легаси»).
Факты проверяй: это учебник для собеседования, ошибка в нём хуже пробела.

## Проверка (обязательно после каждой статьи)

Из `k:\Project\cursor_test\nine-to-eighteen\ui` в PowerShell:

```
$env:PYTHONIOENCODING='utf-8'; python .enrich-check.py src/data/learn/<папка>/<файл>.md
```

Скрипт печатает счётчики (sections, diagrams, quiz, code) и строки `PROBLEM:`; последняя строка —
`mermaid: checked N, failed 0`. Статья готова, когда PROBLEM нет и mermaid failed 0.
Ожидаемо: quiz = было + 3; у тонких diagrams = 2, code ≥ 1, sections = было + 1.
