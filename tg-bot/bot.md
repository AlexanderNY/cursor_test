Требуется создать сервис бота работы с внешними сервисами. Задачи ставятся через сервис sceduller, данные для поста хранятся в базе данных. gateway для перенаправления запросов от сервиса к сервису со следующим функционалом:
CORS
    доступ get, post, put разрешен с сервиса api-gateway
    URL используемых сервисов должны быть перечислены в конфигурационном файле  
Принцип работы бота
    Сервис bot должен запрашивать расписание с сервиса sceduler
    Публикация постов должна проводиться в соответствии с полученным расписанием
    Данные для публикации нужно брать из базы данных
    Иформация об опубликованных постах должна сохраниться в базе данных (для дальнейшего сбора статистики)


маршрутизация запросов
    сервис auth
        перенаправить запросы с сервиса ui-app на сервис auth
        запрос с ui-app post /auth/register нужно преобразовать в post /register на сервис auth
        запрос с ui-app post /auth/login нужно преобразовать в post /login на сервис auth
        запрос с ui-app post /auth/refresh нужно преобразовать в post /refresh на сервис auth
        запрос с ui-app post /auth/logout нужно преобразовать в post /logout на сервис auth
        запрос с ui-app get /auth/profile нужно преобразовать в get /profile на сервис auth
        запрос с ui-app post /auth/profile нужно преобразовать в put /profile на сервис auth
        запрос с ui-app post /auth/verify нужно преобразовать в post /verify на сервис auth
        запрос с ui-app post /auth/reset-password нужно преобразовать в post /reset-password
    сервис tg-bot
        Если telegram запрашивает данне у пользователя, требуется перенаправить их на api-gateway и сообветственно на ui-app
    сервис vk-bot
    сервис wp-bot
    сервис url-bot
