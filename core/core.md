Требуется создать сервис авторизации со следующим функционалом 
1. Проверка Healthcheck все сервисов
        запрос get /healthchecks на сервис core
        запрос запускает последовательно опрос всех сервисов (запрос к каждому сервису /healthcheck но через API Gateway)
2. Проверка статистики работы сервиса
        запрос get /statistics на сервис core
        запрос запускает последовательно опрос всех баз данных и таблиц для сбора информации о том сколько постов собрано, обработано и опубликовано каждым из ботов 
3. Управление публикациями 
С ui-app будут направлены данные приложения пользователя

Для telegram 
        Профиль
        checkbox атрибут публикации (да или нет) 
        checkbox атрибут сбора (да или нет)
        Option сразу при обнаружении нового поста
        Option по временным интервалам
        Временные интервалы (формат HH:MM), до 3 интервалов 
        api id
        api hash
        chats to read пример: -01001677806302
        условия для сохранения сообщения
        channel to post = -1002009872429
        checkbox для обработки сообщения
        описание требующейся обработки
        по запросу Post /tg/profile
        Все атрибуты требуется хранить в таблице настроек telegram специализированно по этому профилю пользователя
        Эти же данные запрашиваются по запросу Get /tg/profile
        
        Также направляется Поле вовода текста (максимум 4 096 символов) по запросу Post /tg/post
        Посты
        Все посты долны храниться в одной таблице "posts"
                ID
                DOMAIN - сайт поста
                URL - URL поста
                TITLE - заголовок поста
                AUTHOR - автор
                AVATAR - путь к картинке автора
                DATE - дата
                POST - текст поста
                SCREENSHOT - путь к скриншоту
                IMAGES - ссылки на изображения из поста
                IMAGEOVERTEXT - текст с картинки
                COMMENTS - количество комментариев
                REPOSTS - количество репостов
                LIKES - количество лайков
                VIEWS - количество просмотров
                AD - флаг, является ли пост рекламой
                STATUS - статус поста 
                TYPE - тип поста
                TOTG - атрибут, отправляется ли в telegram
                TOTW - атрибут, отправляется ли в twitter
                TOWP - атрибут, отправляется ли в wordpress
                TOVK - атрибут, отправляется ли в vkontakte
