Требуется создать сервис авторизации со следующим функционалом 
1. Регистрация и аутентификация
Регистрация (Sign Up): Создание нового пользователя. Принимает логин, пароль и email, возвращает статус успеха и сразу пару токенов (access_token и refresh_token).
POST   /register          - регистрация

Вход (Sign In / Login): Проверка учетных данных (логин/пароль). В случае успеха сервис выдает:
access_token: Краткосрочный токен для доступа к ресурсам.
refresh_token: Долгосрочный токен для обновления пары.
POST   /login             - вход

GET    /verify/    - верификация email

2. Управление сессиями (Токенами)
Обновление токена (Refresh Token): Принимает старый refresh_token, проверяет его валидность и выдает новую пару (Access + Refresh). Это позволяет пользователю не вводить пароль снова после истечения Access-токена.
POST   /refresh           - обновление токена

Выход (Logout): Аннулирование refresh_token в базе данных и добавление текущего access_token в «черный список» (blacklist).
POST   /logout            - выход

3. Проверка и безопасность
Валидация (Validate/Verify): Эндпоинт для других микросервисов, чтобы проверить, является ли предоставленный JWT валидным и активным.
POST   /verify-token      - валидация токена (для других сервисов)

Сброс пароля (Password Reset): Запросы на инициацию сброса (отправка письма) и подтверждение смены пароля.
POST   /reset-password    - сброс пароля

4. Работа с профилем
Получение профиля (Get Me/Profile): Возвращает данные о текущем пользователе на основе JWT в заголовке.
GET    /profile           - профиль пользователя

Изменение данных профиля - принимает обновленные данные о текущем пользователе на основе JWT в заголовке.
PUT    /profile           - обновление профиля

Отзыв всех сессий: Позволяет пользователю выйти со всех устройств сразу (удаление всех Refresh-токенов пользователя).
POST   /all_logout            - выход
