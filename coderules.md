Для обычных переменных использовать стиль snake_case
    Избегать односимвольных имён, кроме случаев, когда их смысл очевиден из контекста (например, i в цикле for)
    Не использовать зарезервированные слова Python как имена переменных (например, list, dict, str)
Имена функций должны состоять из маленьких букв, а слова разделяться символами подчёркивания в стиле snake_case, но имя функции начинать с глагола
Имена констант (значения, которые не должны изменяться) писать заглавными буквами с подчёркиваниями между словами, например API_KEY
Стиль именования для классов — PascalCase (или UpperCamelCase) — каждое слово начинается с заглавной буквы, без разделителей
