# Черновики канала: сезон 1, выпуски 01–10

Готовые тексты для Telegram. Обращение на **вы**. Карточка выпуска — как в [PERSONAL_BRAND.md](../PERSONAL_BRAND.md).

Сквозной учебный сервис студента: **заявки** (tickets) — свой маленький API + UI + БД. CopyParse — референс, не форк.

## Как публиковать

В каждом файле три блока:

1. **Пост** — первое сообщение в канале (1.5–2.5 тыс. знаков).
2. **Лаба** — второе сообщение треда / комментарий.
3. **Ссылки** — третье сообщение.

Схему из блока **Схема**: вставьте в [mermaid.live](https://mermaid.live), экспортируйте PNG и приложите к посту.

Не копируйте в канал заголовки `#` и служебные комментарии файла.
